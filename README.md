# Wild West Frontier Pack Minecraft Modpack Research Guide

Wild West Frontier Pack is an open source Minecraft modpack research guide for Minecraft Java 1.20.1 on Forge, covering Western themed horses, firearms, NPCs, world generation, quests, exploration, wildlife, sound, weather, transport, and multiplayer setup.

## Install

1. Install Minecraft Java Edition 1.20.1.
2. Install the Forge loader for Minecraft 1.20.1.
3. Read `MODPACK_RESEARCH.md`.
4. Check every linked CurseForge project for an explicit Minecraft 1.20.1 Forge file.
5. Download only matching files and their listed dependencies.
6. Install gameplay, world generation, structures, quests, NPCs, and transport mods on both the server and every client unless the mod author specifies otherwise.
7. Install camera, sound, shader, rendering, HUD, and visual animation mods on each client when their project pages identify them as client-side.
8. Start with a fresh test world before using the selected world generation mods in a long-term save.

## Use

1. Use the ranked picks to choose one firearm framework, one NPC approach, one transport system, and a compatible selection of structure and biome mods.
2. Use FTB Quests for authored campaign chapters and rewards.
3. Use Bountiful for repeatable jobs and bounty-style objectives.
4. Use Easy NPC for configured dialogue and encounters.
5. Use Guard Villagers and configured hostile encounters to create town defense and danger.
6. Use Create with Create: Steam 'n' Rails for mechanical rail systems where the selected files are compatible.
7. Use AstikorCarts Redux for horse-drawn transport only if its Minecraft 1.20.1 Forge file and dependencies are available.
8. Combine terrain, structure, wildlife, sound, weather, and camera mods gradually.
9. Test server startup, multiplayer joining, quest persistence, NPC interaction, firearm synchronization, horse and cart behavior, structure generation, and loot distribution before release.
10. Treat the guide’s candidates as items requiring file verification. It does not claim that every listed project currently has a compatible file.

The guide contains 47 real project candidates organized into horses and transport, combat and hostile encounters, frontier world generation, activities and progression, missions and NPCs, and immersion.

Key limitations are documented clearly. The listed projects do not provide a complete RDR2-style conversion with AAA horse animation, autonomous armed human gangs, scripted train robberies, a full wanted-level system, or a ready-made campaign. These systems require configuration, authored content, a compatible additional project, or custom development.
